# QuietVinyl Mixxx fork

Read QUIETVINYL.md before editing. Keep the maintained branch based on official
Mixxx 2.5.6. Source changes belong here; the companion QuietVinyl repository pins
a full source commit and owns resources, helper, tests and packaging.

Coordinate shared source ownership. Commit and push completed changes to the
default branch; do not create pull requests unless asked. Never deploy or restart
the shared Pi without explicit coordination. Keep media, credentials, profiles,
downloaded dependencies and compiled applications out of Git.
